# lemonade
Dotfiles to survive changing computers (macOS) and keep that configuration freeesh like a lemonade. 🍋🥤☕️

## Install

```bash
git clone git@github.com:ollecoffee/lemonade.git ~/lemonade
~/lemonade/install.sh
```

It installs Homebrew and the apps, then links the configs into `~`. Safe to re-run.
